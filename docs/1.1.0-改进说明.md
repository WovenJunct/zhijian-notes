# 纸间 1.1.0 改进说明

保留纸张手账、奶油白与陶土橙的界面，围绕日常记录、整理和找回内容改进。应用运行仍无联网权限，全部编辑器资源、SQLite 数据和图片均在本机。

## 本次功能

- 笔记卡片只显示正文第一条非空行，超出宽度省略。旧版笔记也从原正文提取摘要，无需逐条重新保存。
- 卡片右上角菜单支持重命名、置顶、收藏、移动、复制、导出和移入回收站；删除后有撤销入口。
- 长按卡片或点击批量整理，可选择本页笔记，批量移动、收藏、导出及删除。
- 列表与网格视图、按编辑时间/创建时间/标题排序、图文与 Markdown 类型筛选。排序及布局保存在本机设置。
- 富文本工具提供正文与 H1—H6、粗体/斜体/下划线/删除线、行内代码、代码块、引用、多级有序/无序/待选清单、链接、对齐、文字颜色、高亮、清除格式和撤销重做。
- 富文本支持基础表格：插入 2×2、增加/删除行列及删除整表。表格工具收纳在格式面板的「表格」中。
- Markdown 增加多级标题、常用文字标记、引用、编号/待选列表、缩进、链接、表格和分隔线插入，以及源码撤销重做。
- 回收站可打开笔记全文和本地图片，只读查看后恢复或永久删除；不会因为查看而修改正文或意外恢复。
- 笔记回顾包含本地日历、字数与记录天数统计、随机翻阅。统一按创建日期统计和筛选，排除回收站记录。

富文本完整格式保留在应用正文及完整 ZIP 备份中。Markdown 是通用文本格式，导出可保留标题、嵌套清单、代码、表格和图片；字体颜色、高亮与对齐不属于标准 Markdown 的通用排版能力。复杂合并单元格、绘画、录音、同步不在本版范围内。

## 参考项目与取舍

已核对项目 README 及源码。只借鉴功能组织与交互思路，没有复制它们的源码、资源或二进制编辑器。

| 参考 | 借鉴到纸间 | 源码核对后的取舍 |
| --- | --- | --- |

原始编辑语法与工具支持同时核对了 [Obsidian 格式文档](https://obsidian.md/help/syntax) 和 [Quill 格式文档](https://quilljs.com/docs/formats)。本版选取能在现有离线架构中完整保存、重开和导出的能力。

## 架构与兼容

- `EditorTools` 管工具面板、选择区和编辑历史，`content.js` 管清洗、纯文本和 Markdown 转换；不将任意 HTML 样式直接存入编辑器。
- `NoteQueries` 统一排序、日期筛选、摘要边界和回顾统计；原生桥继续白名单分派并串行执行数据操作。
- 批量整理在 SQLite 事务中完成，任一记录不可用时回滚整次操作。使用稳定 UUID，不以列表位置修改内容。
- UI 显示偏好通过原生 SharedPreferences 保存，不将正文放入浏览器存储。
- 包名、发布密钥、数据库版本 1、备份格式版本 1 保持兼容。安装新版时直接覆盖；不要先卸载。安装前仍可在设置中备份一份。

实际验证与边界见 [验证记录](verification.md)，构建步骤见 [开发与测试](development.md)。
