# 纸间 1.2.0

保持奶油纸色、陶土橙和书页式排版。常用编辑工具仍在底部，图片工具按需出现，长文与整理工具收进笔记菜单。

## 图片与手写

- 图文中点图片后，可设置 10%—100% 宽度、左中右对齐、上下移动，也可用边框手柄拖动缩放或移动到正文位置。布局跟随正文保存，支持编辑撤销。
- 图片编辑提供裁剪框、旋转、水平/垂直翻转、画笔、颜色、粗细、橡皮、清空标注、撤销重做，以及预览缩放和平移。
- 「Aa → 手写」打开纸页画板，可用手指或触控笔书写。保存后作为本机 PNG 插入图文或 Markdown 笔记；点图片「续写」可继续添写。
- PNG 保存经过原生格式、字节数与尺寸校验，以新 UUID 原子另存。编辑过程取消不修改原图，保存失败保留画布供重试。

编辑画布最长边 2048 像素、总像素不超过约 200 万。GIF 编辑后为静态 PNG。手写保存后合并为图片底图，橡皮只擦除本次新增标注，不提供笔迹识别或逐笔重排。

## 日常工具

| 工具 | 使用方式 |
| --- | --- |
| 查找替换 | 笔记工具中按正文文字查找，可区分大小写、逐处替换或确认后全部替换；支持撤销 |
| 标题大纲 | 列出本页标题并跳转，Markdown 代码围栏内的标题不会误入大纲 |
| 笔记链接 | 插入指向本机笔记的链接，也可查看其他哪些笔记提到了本页 |
| 历史版本 | 自动保留修改，也可手动保存当前版本，预览并恢复标题、正文与文件附件 |
| 模板 | 内置每日记录、会议纪要、读书笔记、每周复盘和项目计划；自定义模板可新建、插入、改名及移除 |
| 日期与提醒 | 待办可单独设置到期日期，也可开启未来时间的本地通知；完成或删除后取消相应提醒 |
| 文件附件 | 单条笔记最多 50 个附件，PDF 等文件复制到私有目录，打开时授权本机阅读器只读访问 |
| 分享导入 | 在其他应用选择「分享 → 纸间」，将文字、图片或文件保存为一条新笔记，单次最多 10 个文件 |

历史最多 12 版、合计约 1.5 MiB，每分钟最多自动保留一版，超限清理较早版本；过大的正文仍可保存，但手动保留或恢复历史可能要求先拆分。历史不能替代完整备份。自定义模板以模板笔记保存，可在普通笔记列表中查看。

提醒需要系统通知权限。应用使用系统允许的非精确本地闹钟，不申请精确闹钟特殊权限；系统省电、关机及厂商后台限制可能延迟提醒。打开应用、系统重启或时间变化时会重新核对待办；已完成、已删除或旧时间的提醒不会再次通知。

## 保存与迁移

完整 ZIP 包含图片、手写、文件附件、历史及模板。历史中的旧图片同样参与引用保留。附件仍限制为单文件 20 MiB；导出 Markdown 时附上可读原文件名，并将一同导出的笔记链接转换为相对 `.md` 链接。

包名及签名保持一致，可覆盖安装。备份结构仍为版本 1，兼容读取旧版备份；新版含通用附件的备份请使用 1.2.0 或更高版本恢复。全部运行资源随包提供，应用没有 INTERNET 权限。
